# PSL Wallet PWA

이 디렉터리는 빌드 단계 없이 정적 호스팅할 수 있는 PSL Wallet 클라이언트입니다.

## 키 보관

개인키는 Web Crypto API의 PBKDF2-SHA256(310,000회)로 비밀번호 키를 만들고 AES-256-GCM으로 암호화합니다. 암호문·salt·IV만 브라우저 저장소에 남으며, 잠금 해제한 개인키는 메모리에만 유지됩니다. 5분 동안 입력이 없으면 자동으로 잠깁니다.

이는 기기 감염, 악성 확장 프로그램, 피싱 또는 변조된 배포물까지 막는다는 뜻은 아닙니다. 프로덕션 사용 전 독립 보안 감사를 진행하고 소액부터 검증하세요.

## 실행

```bash
npm start
```

`http://localhost:4173`에서 확인합니다. 정적 배포 시 `pwa/` 디렉터리의 내용 전체를 HTTPS로 서비스하세요.
